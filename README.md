# تطبيق القرآن الكريم

مشروع Flutter لتطبيق القرآن الكريم ومواقيت الصلاة.

## صفحة تلاوات ياسر الدوسري
الملف `web/yasser.html` يعيد بناء الجزء الناقص من كود القارئ:
- تحميل أسماء السور الـ114 من API.
- بحث فوري باسم السورة.
- مشغل مستقل لكل سورة مع إيقاف بقية المشغلات.
- الانتقال التلقائي للسورة التالية بعد انتهاء التلاوة.

## بناء APK
يبدأ GitHub Actions البناء تلقائياً عند كل تحديث على فرع `main`، أو يمكن فتح تبويب Actions وتشغيل workflow باسم **Build Android APK**.
بعد نجاح البناء، افتح تشغيل البناء ثم قسم Artifacts لتنزيل `quran-prayer-app-release`.

> تنبيه: صفحة ياسر محفوظة حالياً كملف ويب مستقل داخل المستودع. بناء APK الحالي يتبع واجهة Flutter الموجودة في `lib/main.dart`، ولا يعني ذلك أن جميع أقسام HTML الأصلية قد دُمجت بعد داخل APK.
